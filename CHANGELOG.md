# Changelog

## 1.0.1 — 2026-08-12

- Accept common cursor-sheet suffixes such as `-Sheet`, search source subfolders, and report ambiguous image matches clearly.

## 1.0.0 — 2026-08-12

- First release of Cursor Cape Builder.
- Drag-and-drop macOS app for building Mousecape v2 themes from 15 PNG sprite sheets.
- Covers 44 macOS cursor states and exports self-contained animated `.cape` files.
